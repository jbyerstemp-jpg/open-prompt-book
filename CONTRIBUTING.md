# Contributing

The easiest way: point your AI at this repository and say

> Read AGENTS.md, then assess this prompt (or idea) against The Open Prompt Book.

It will tell you where it fits, what to change, a proposed 0–5 score, and
the next step. Nothing is published until you approve a pull request.

## Ways to help (no membership needed)

- Suggest an improvement to an entry.
- Report something unclear, wrong, or that did not work for you.
- Propose a new entry for a need the book does not cover.
- Report a safety concern ([SECURITY.md](SECURITY.md)).

## Doing it by hand

1. Read [BOOK_RULES.md](BOOK_RULES.md).
2. Copy [templates/entry.md](templates/entry.md) to `entries/<short-name>/entry.md`
   (lowercase letters, numbers and hyphens).
3. Open a pull request. A member can sign the submission for you, or you
   can request membership in the pull request.

## Becoming a member

Open an issue asking to join, with your GitHub name and your SSH public
key (the `.pub` file, never the private one). New members start at tier A.
See [GOVERNANCE.md](GOVERNANCE.md) for how responsibility grows.
